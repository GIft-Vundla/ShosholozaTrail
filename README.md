# ShosholozaTrail

ShosholozaTrail is an interactive, offline-first journey mapper for the Pretoria–Cape Town rail corridor. It turns a long-distance train journey—including periods of weak connectivity and delays—into a guided experience built around local attractions, culture and community stories.

## Project overview

The passenger experience is designed to:

- download a route and story pack before departure;
- remain useful when mobile connectivity weakens;
- show journey progress and location-linked story triggers;
- preserve community attribution and content provenance;
- adapt content when the train stops or is delayed;
- gate local visit actions behind verified dwell-time and safety information; and
- measure story engagement, saved places and passenger relevance ratings.

## Interactive HTML prototype

[Open the interactive prototype](./ShosholozaTrail_Interactive_HTML_Prototype.html)

The standalone prototype contains six connected frames:

1. Board and download
2. Live journey map
3. Story and provenance
4. Delay mode
5. Safe local action
6. Arrival and outcomes

It includes working prototype interactions such as route-pack download progress, journey-mode selection, route-stop previews, simulated audio playback, delay-duration filtering, operator dwell-time verification, saving a local place and journey rating.

### Run locally

1. Clone or download this repository.
2. Open `ShosholozaTrail_Interactive_HTML_Prototype.html` in a modern browser.

The prototype is self-contained and does not require installation, a development server or an internet connection.

## Prototype status

This repository currently represents a concept and interactive prototype. Partner listings, contributor names, operator feeds, live journey states and outcome metrics shown in the prototype are demonstration content unless explicitly verified. Production use would require operator integration, partner onboarding, community content approval, rights management, accessibility testing and passenger validation.

## Corridor represented

The prototype focuses on the Pretoria–Cape Town journey and uses corridor anchors such as Johannesburg, Kimberley, De Aar, Beaufort West and Matjiesfontein to demonstrate how location-aware stories and tourism discovery could work along the route.
